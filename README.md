# Ping-Enquetes

## Sobre o projeto

Aplicação de enquetes em ASP.NET Core e C#, com destino .NET 9. Reúne controladores, modelos, serviços, telas e um arquivo de usuários em JSON.

## Como explorar

Instale o SDK .NET 9, restaure as dependências e execute `dotnet run --project WebApplication1/WebApplication1.csproj`. Consulte o endereço exibido pelo servidor.
